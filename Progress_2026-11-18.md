## Tests and evidence

Four new HTTP test methods cover:

1. Exactly 15 minutes included; 16 minutes excluded; 14-minute tolerance excludes a 15-minute gap. Reverse direction excluded. Adjacent Macau dates at 23:55/00:05 excluded despite only 10 minutes between them. Same clock time on different dates excluded.
2. Default ranking by time difference, completed shared rides, publish time, then ID; publish time outranks ID; repeat queries and page slices retain order. Alternative departure sorting and invalid sort rejection checked.
3. Full rides excluded; withdrawal restores one seat; minimum-seat filter applied; reconfirmation and cancellation states excluded.

The ranking test inserts controlled completed-history fixtures into a temporary database. Other ride creation, matching, moderation and state changes use HTTP. Fixture data are not claims about real users or completed travel.
